# Tower of Hanoi (TOH) – DSA Group Project

This project is a collaborative Data Structures and Algorithms (DSA) group project based on the Tower of Hanoi problem. The project demonstrates the use of recursion and algorithmic problem-solving techniques to solve the classic TOH puzzle efficiently.

---

## 📌 Features
- Tower of Hanoi implementation
- Recursive algorithm demonstration
- Step-by-step disk movement
- Simple and interactive execution

---

## 🛠️ Technologies Used
- C++
- Data Structures and Algorithms (DSA)
- Recursion

---

## 📖 About Tower of Hanoi
Tower of Hanoi is a classic mathematical and logical puzzle consisting of:
- Three rods
- Multiple disks of different sizes

The objective is to move all disks from the source rod to the destination rod following these rules:
1. Only one disk can be moved at a time
2. A larger disk cannot be placed on a smaller disk
3. Only the top disk can be moved
